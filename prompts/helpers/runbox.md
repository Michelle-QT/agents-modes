`runbox` is the no-ask way to run Research shell work: any command, including reading, writing, network, and executing code. It runs inside a locked container that has full internet, the project working directory, unreadable overlays for in-tree secrets, and read-only overlays for forbidden project paths. The overlays are computed at session start, so a file matching a secret pattern created after launch is readable inside the box.

In Research mode, use `runbox` for every Bash/shell command by default. Do not run plain Bash for routine shell work such as `ls`, `find`, `rg`, `git status`, `git diff`, tests, scripts, package commands, or network commands. If you need a shell command in Research and it is not deliberately an outside-host command requiring user approval, the command shape is `runbox ...`. Do NOT concatenate runbox commands with pipes etc; that will prompt the user.
